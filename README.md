# 말랑말랑 스토리 오븐 / Squishy Story Oven

Streamlit bilingual (Korean/English) storybook app for children.

## Deploy

Upload these files to the root of the GitHub repository:
- `app.py`
- `requirements.txt`
- `story_oven_home.png` (user-provided cover image)
- `marshmallow_mascot.png`
- `story_oven.png`
- `story_oven_banner.png`

In Streamlit Community Cloud, set the app entrypoint to `app.py` and add this in the app's **Settings → Secrets**:

```toml
GEMINI_API_KEY = "your-private-key"
```

Optionally set `GEMINI_MODEL`. Do not commit API keys to GitHub.

## How it works

The landing page displays the supplied cover image with a real Streamlit button beneath it. Choose Korean or English in the language selector. After clicking, choose topic and sauce, genre, character, location, story events, then write your ending. The app creates an illustrated storybook with a downloadable HTML version. Illustrations are drawn locally based on settings, not generated by an image model.
